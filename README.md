# 📚 LearnLingo — Language Tutors Platform

## 📖 About the Project

LearnLingo is a web application designed to help users find and connect with professional language tutors.
Users can browse tutors, filter them by different criteria, add favorites, and book trial lessons.

The platform provides a clean and interactive interface, making it easy to explore tutors and manage personal preferences.

---

## ✨ Features

- 🔐 User authentication (registration, login, logout) using Firebase
- 👩‍🏫 Browse a list of tutors
- 🔍 Filter tutors by:
  - Language
  - Level
  - Price
- ❤️ Add/remove tutors from favorites (personalized per user)
- 📄 View detailed tutor information
- 📅 Book a trial lesson (form with validation)
- 🎨 Theme switcher (multiple color themes)
- 🔔 Toast notifications for user actions

---

## 🧰 Tech Stack

- React — UI development
- React Router — routing
- Firebase (Auth + Firestore) — authentication & database
- React Hook Form + Yup — form handling & validation
- React Hot Toast — notifications
- CSS Modules — styling
- LocalStorage — storing user favorites
